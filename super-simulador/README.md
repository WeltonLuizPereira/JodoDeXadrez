# Super Simulador (Core)

Este diretório contém uma implementação inicial em Node.js das funções de
processamento estatístico e análise descritas na documentação do **Super
Simulador**. O foco aqui é a lógica de cálculo, que pode ser utilizada tanto
em uma aplicação React quanto em scripts de linha de comando.

Para executar um exemplo de uso:

```bash
npm start
```

O exemplo carrega dados históricos de Mega-Sena e Lotofácil e exibe as
estatísticas básicas.
